## 1. 选型总表（冻结）

| 角色 | 基准型号 | 备选 | 物理量 / 动作 | 接口 |
|------|----------|------|---------------|------|
| 冠层 PPFD（主） | **Apogee SQ-500** | LI-COR LI-190R | µmol·m⁻²·s⁻¹ | 模拟 mV / 配记录仪 |
| 工程光照（辅） | **建大仁科 RS-GZ-N01** | RS-GZ-*-AL（铝壳 IP65） | lux 0–65535 / 0–20万 | RS485 Modbus-RTU |
| 实训节点 | **BH1750** | VEML7700 | lux | I2C |
| 补光灯 | **智圣普 ZPDM651**（100–300W） | 同规格 0–10V/PWM 温室 LED | 0–100% 调光 | 0–10V / PWM / 电阻 |
| 调光网关 | RS485→0–10V（晟瀚 L100 类） | PLC 模拟量模块 | 多路 dimming | Modbus-RTU |
| 遮阳/遮阴 | **创明众联 B 系列** | 田工智联遮阳/卷帘控制器 | 开度 0–100% | RS485 开/关/停/定位 |

**存在性说明（可查厂商页）：**

- Apogee SQ-500 / LI-COR LI-190R：科研级量子传感器，温室/生长室常用  
- 建大仁科 RS-GZ：农业大棚壁挂光照变送器，Modbus 标准  
- ZPDM651：温室网在售，三合一调光，IP65  
- 创明众联 B：开放 RS485 协议，支持运行到任意开度

## 2. 传感侧细节

### 2.1 Apogee SQ-500（主契约）

| 项 | 值 |
|----|-----|
| 测值 | PPFD（PAR），µmol·m⁻²·s⁻¹ |
| 典型输出 | 自供电模拟约 0–40 mV；标定约 100 µmol·m⁻²·s⁻¹ / mV（以出厂证书为准） |
| 场景 | 冠层上方 / 冠层下透射均可 |
| 平台字段 | `ppfd`（必填） |

### 2.2 LI-COR LI-190R（备选）

| 项 | 值 |
|----|-----|
| 测值 | 同上 PPFD |
| 灵敏度 | 约 5–10 µA / 1000 µmol·m⁻²·s⁻¹（需分流电阻） |
| 场景 | 与 SQ-500 同级科研对照 |

### 2.3 建大仁科 RS-GZ-N01

| 项 | 值 |
|----|-----|
| 供电 | 10–30 VDC |
| 协议 | Modbus-RTU，RS485 |
| 量程 | 0–65535 Lux（可订 0–20 万） |
| 平台字段 | `lux`；仿真时 `ppfd ≈ lux * k` |

### 2.4 BH1750 / VEML7700

| 项 | 值 |
|----|-----|
| 用途 | 实训节点、低成本多点布局演示 |
| 限制 | 非量子传感器；答辩须声明「工程近似」 |
| BH1750 | I2C `0x23`，约 1–65535 lx |
| VEML7700 | 量程更大，更耐强光 |

### 2.5 lux → PPFD 换算（仿真默认）

自然光与红蓝 LED 光谱不同，**无统一精确系数**。演示默认：

| 光源假设 | 建议 k（ppfd ≈ lux × k） | 说明 |
|----------|--------------------------|------|
| `SUNLIGHT` | 0.0185 | 常见粗算量级 |
| `RB_LED` | 0.012–0.020 | 需标定；默认取 0.015 |
| `FULL_LED` | 0.014 | 可配置 |

配置项：`light.conversion.profile` + `light.conversion.k`。石斛控制阈值一律按 **ppfd** 比较。

## 3. 执行侧细节

### 3.1 智圣普 ZPDM651

| 项 | 值 |
|----|-----|
| 功率档 | 100 / 150 / 200 / 300 W |
| 光谱 | 450+660 nm 或全光谱（可定制） |
| 调光 | **0–10V / PWM / 电阻**，0–100% |
| 防护 | IP65，吊装 |
| 平台命令 | `SET_DIMMING` + `dimmingPercent` |

### 3.2 调光链路

```text
平台 MQTT  →  边缘网关  →  RS485/模拟量  →  LED 驱动 0–10V/PWM  →  灯具
```

仿真：直接置 `actuator.dimmingPercent`，3D 按功率×透过率重算冠层。

### 3.3 遮阳电机（创明众联 B 类）

| 项 | 值 |
|----|-----|
| 动作 | 开 / 关 / 停 / **运行到开度%** |
| 总线 | RS485 |
| 平台命令 | `SET_OPEN_PERCENT` + `shadeOpenPercent` |
| 语义 | `0` = 全收（最大透光）；`100` = 全展（最大遮光） |

## 4. 分区与安装约定（仿真/真棚共用）

**平面与三维坐标真源：** [GREENHOUSE-LAYOUT.md](./GREENHOUSE-LAYOUT.md)（`cq-demo-bay-v1`：16×7 m，长轴东西，南向采光）。

| ID 前缀 | 含义 | 示例 |
|---------|------|------|
| `PAR-` | PPFD/光照测点 | `PAR-ZONE-A-01` |
| `LAMP-` | 补光灯 | `LAMP-ZONE-A-01` |
| `SHADE-` | 遮阳轴/网 | `SHADE-ZONE-A` |
| `ZONE-` | 逻辑分区（作物床） | `ZONE-A` |
| `BED-` | 栽培床（设计层） | `BED-A-S` |
| `ENV-` | 空气温湿度（Should） | `ENV-BAY-01` |

每测点、每灯具在 3D 中有 `position: {x,y,z}`（米），**必须与布局 JSON 一致**。  
一区：≥3 个测点 + 多灯覆盖三床 + 半跨外遮阳。
