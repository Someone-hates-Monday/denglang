| 现象 | 根因 |
|------|------|

## 1. 文献与开源参照（设计约束）

| 来源 | 采纳要点 |
|------|----------|
| 园艺补光工程实践（灯高–间距耦合） | **安装高度以冠层计**，非地坪；升高→重叠增、峰值降；无万能间距，用网格 PPFD 验收 |
| 生产均匀度目标 | 演示目标 **U₀ = min/avg ≥ 0.6**（床面网格）；科研级 0.7–0.8 作 Should |
| [horticulture-lighting-simulator](https://github.com/luminousphotonics/horticulture-lighting-simulator) | 冠层测量面伪彩；灯具→接收面；MVP 用解析/响应，Stretch 可 Radiance 烘焙 |
| 本仓库 RESEARCH：响应矩阵 | `PPFD = A·d + τ·E_sun`；控制求 **分灯 d**，非单标量 |
| 石斛/金线莲配方 | 低目标带 → 单灯峰值下调、靠密度与分调保均匀，忌近距高亮热点 |

**冻结经验公式（演示级，非 IES 真值）：**

- 灯–冠层净空 **H ≈ 0.90–1.00 m**（灯心 Z − 测光面 Z）  
- 沿床（东西）中心距 **≈ 2.0–2.3 m**（约 2–2.5×H 的宽松比，配合半角 ~55°）  
- 跨床：一床一排灯，灯 Y = 床中心，减少跨床串扰

## 2. 布灯方案 v1.3

### 2.1 通则

| 项 | v1.3 冻结值 |
|----|-------------|
| 灯心高度 L0 | **Z = 1.85 m**（石斛测面 0.90 → 净空 **0.95 m**） |
| 灯心高度 L1（叠层） | **Z = 2.15 m**（上层测面 1.35 → 净空 **0.80 m**） |
| 朝向 | 光轴 **竖直向下** `(0,0,-1)`；灯条长轴沿 **+X（东西）** |
| 半功率角 | `beamHalfAngleDeg = 55`（锥外快速衰减） |
| 峰值 | A 区 L0 **`maxPpfdAtCanopy=95`**；B 区 **80**；L1 **55**（密布后降单灯峰值） |
| 控制粒度 | **床（bed）为主**；同床 3 灯同步微调；跨床独立；L1 独立 |

### 2.2 ZONE-A（9×L0 + 2×L1）

每床东西 **3 灯**，Y = 床中心：

| 床 | Y | 灯 SN · X |
|----|---|-----------|
| BED-A-S | 1.40 | A-01@1.75 · A-02@4.00 · A-03@6.25 |
| BED-A-M | 3.50 | A-04@1.75 · A-05@4.00 · A-06@6.25 |
| BED-A-N | 5.60 | A-07@1.75 · A-08@4.00 · A-09@6.25 |
| L1 中/北 | 3.50 / 5.60 | A-L1-01@4.00 Z=2.15 · A-L1-02@4.00 Z=2.15 |

### 2.3 ZONE-B（9×L0）

同构，X = 9.75 / 12.00 / 14.25；Y = 1.40 / 3.50 / 5.60；Z = 1.85；SN `LAMP-ZONE-B-01`…`09`。

### 2.4 前端观感

灯条几何缩小为约 **0.35×0.03×0.08 m**（或 GLB 等比缩小），避免「灯比床还大」。

## 4. 光场仿真升级

### 4.1 日光（写清公式）

室外曲线 `E_out(t)`（ClimateProfile）已存在。棚内：

```
elevFactor = sin(elevation)          // 夜间 0
diffuseF   = fog/overcast ? 0.85 : 0.35…0.55
τ_shade    = physicalShade(closed, elev, diffuse)
τ_cover    = 0.65

E_base     = E_out × τ_cover × τ_shade × elevFactor
E_dir      = E_base × (1 − diffuseF) × bedSunFactor(y, az, elev) × sunOcclusion(x,y)
E_dif      = E_base × diffuseF × bedSunDiffuse(y)
E_sun      = E_dir + E_dif
```

- **太阳方向**：由 `solarElevationAzimuth`（重庆纬度近似 + 日型赤纬）给出，API 已暴露角度；本版在 effective-light 增加 `sunModel` 说明字段。  
- **sunOcclusion**：直射分量；上层苗床/搁架 AABB 对下层测点投软影（透射 0.25–0.4）；漫射几乎不挡。

### 4.2 补光（光束 + 遮挡）

单灯对点 `(x,y,z)`：

```
r⃗ = P − L，  dist = |r⃗|，  cosθ = (−r̂)·â   // â 光轴向下
若 θ > beamHalfAngle → 贡献×边缘衰减（cos 平滑到 0）
I = maxPpfd × (H_design²) × cosθ / dist² × dim%
× bedOcclusion(L→P)   // 穿过其它床冠层则衰减
```

`bedOcclusion`：射线与其它床顶面矩形求交，每层乘 `0.35`（叶幕吸收演示值）。

### 4.3 分床有效光

对床 `b`：落在床矩形内的网格点 AVG / MIN → `bedEffectivePpfd[b]`。  
区级 `effectivePpfd` = 各床 AVG 的平均（或传感器聚合，保持兼容）。

## 5. 控制升级：分床 / 分灯

| 层级 | 行为 |
|------|------|
| 外遮阳 | 仍半跨区级（机械粗档），经济性规则不变 |
| 补光 AUTO | **按床**：该床 AVG 相对动态目标 → 只调 `servesBeds` 含该床的灯 |
| 同床灯 | 同步同一调光（演示）；Should：按灯下传感器微调 ±dimStep |
| 禁止 | 再用「全区平均一刀切」作为唯一动作 |

工单：大开度仍可挂 **代表灯 SN** 或床号（后续字段 `bedId`）。

## 6. 验收

1. 灯心 Z=1.85，视觉上明显离开冠层；床面热力无大片死黑。  
2. 单床 Mid 点 PPFD 在配方目标带可追到；北床可高于南床补光（分调）。  
3. 关一层 L1 或加大上层遮挡时，下层直射分量可见下降。  
4. `sunModel` / 高度角随压缩日变化，冬雾 `diffuseF` 高、南北差小。  
5. 床面网格 U₀（补光为主时段）≥ 0.55 演示及格。
