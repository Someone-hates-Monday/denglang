## 1. 总判

| 维度 | 结论 |
|------|------|
| **答辩 / 约 3 分钟演示闭环** | **基本达标**：测光 → 配方 → 补/遮 → 工单 → 日志/告警 → 3D 光场 |
| **课程「真实场景感」** | **半真半演**：角色分权与 3D 点选处置已落地；协同深度、沙箱/维护窗仍薄 |
| **提交发布包** | **材料大体齐全**；硬缺口主要是 **稳定 jar 归档**、**答辩视频录制**、**空机按 DEPLOY 验收一轮** |

一句话：当前是可演示的**实训原型**，不是可交付运维的生产系统。对**课程发布**够用；对**真实大棚**不够。

## 2. 现有成果（可依赖）

### 2.1 控光闭环（PRD Must 主线）

| 能力 | 说明 |
|------|------|
| 档案与仿真 | `gh_zones` / `gh_devices` / 配方；tick 驱动有效光 |
| 规则 | 欠光补光、过光先降灯、硬限遮阳粗档；重庆日型 + 压缩演示日 |
| 工单门控 | 超阈值：**冻结为执行 + 审计 WO**（先下发，再建 PENDING 复核）；`approve` ≠ 二次下发；`claim` 接单叙事 |
| 审计 | `gh_control_logs`、`gh_alarms`、MQTT command ACK（硬件仿真 profile） |
| 空间 | 3D 棚体、双层灯位、冠层白→红热力、分区聚焦、日曲线与经济性摘要 |

| 报告 | `gh_reports`：日光合草稿 + 学员实训草稿 + 批阅壳 |

## 3. 与「实际场景要求」的差距

| 场景期望 | 现状 | 差距性质 |
|----------|------|----------|
| 在棚内按灯位发现并处理问题 | 3D 光晕 + 点选；WO 已挂目标 SN | **方向正确**；远距聚合 / 状态过滤仍缺 |
| 工单明确挂到某台设备 | DB `target_device_sn` + 前端光晕已用 | **本轮对齐**；侧栏列表仍可再强化 SN 展示 |
| 学员沙箱可调、生产只读 | 生产区只读 + 实训报告 | **ZONE-SIM 未真正落地** |
| 权限申请 / 站内联系 / 维护窗 | 文档有 | **R2 / 联系 / 维护窗未做** |
| 农艺在线改配方硬限 | 仅绑定 | `recipe.edit` 未做 |
| 真机 MQTT 默认真遥测 | 仿真写库为主 | 答辩可过 |
| Agent 当产品核心 | 前端知识问答 | **勿宣传为 RAG 控灯** |
