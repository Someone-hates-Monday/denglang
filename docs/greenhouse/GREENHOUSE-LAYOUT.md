## 0. 设计原则

1. **先棚后码**：先定边界、朝向、床位、灯高、测点，再改 `gh_devices` / 光场网格 / Three.js。  
2. **可落地**：尺寸取重庆常见**单跨拱棚示范单元**量级（非虚拟大棚）；灯与传感器型号见 BOM。  
3. **可计算**：统一右手坐标系与日光约定，便于自然光项与补光响应矩阵。  
4. **分区服务作物**：西半区石斛（需精细双向控光），东半区耐阴/切换作物（金线莲 ↔ 草莓叙事）。  
5. **当前软件若与本文冲突**：以本文为准，记入「待工程同步」清单（文末）。

## 1. 场址与朝向

| 项 | 冻结值 | 依据 |
|----|--------|------|
| 场景 | 重庆近郊设施农业示范棚 · **单跨拱棚一单元** | 课程可建、可答辩 |
| 纬度近似 | 29.5°N | 重庆城区量级 |
| **长轴** | **东西向**（Length 沿东—西） | 南侧长边受冬半年日照；配合冬雾补光叙事 |
| **短轴** | **南北向**（Width 沿南—北） | 南床光更强，北床偏弱 → 测点可显均匀度 |
| 膜材 | PO 膜 / 透光率 **τ_cover = 0.65** | 常见老化膜量级；可标定后改 |
| 遮阳 | **外遮阳**优先（夏正午）；开度语义见 MQTT | BOM：创明众联 B 类 |

### 1.1 坐标系（必须遵守）

```
原点 O：棚内地坪 · 西南角（南侧外墙内侧 × 西侧山墙内侧）
+X → 东（沿棚长）
+Y → 北（沿棚宽）
+Z → 上（地坪为 0）

单位：米（m）
```

**日光约定（仿真）：**

| 时刻概念 | 太阳方位 | 光线入射倾向 |
|----------|----------|--------------|
| 正午 | 正南（方位角 180°） | 主要从 **南侧（Y≈0）** 进入 |
| 上午 | 偏东南 | +X 侧略强 |
| 下午 | 偏西南 | −X 侧略强 |
| 漫射日（冬雾/阴） | 近似各向同性 | `diffuseFraction` 升高，方向项权重下降 |

自然光到达冠层前：`E_out_par × τ_cover × (1 − maxBlock × shadeClosed)`，再按床位南北位置做轻微梯度（南床系数略高，见 §6）。

## 2. 棚体边界与剖面

### 2.1 平面尺寸

| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 棚内净长 | L | **16.0 m** | 东西向可用栽培长度 |
| 棚内净宽 | W | **7.0 m** | 南北向 |
| 檐高（肩高） | H_g | **2.8 m** | 侧墙/拱脚上方作业高度 |
| 脊高 | H_r | **3.8 m** | 拱顶 |
| 外轮廓示意 | — | ≈16×7 平面 | 不含外走道；走道在棚外南侧预留 ≥1.2 m |

`geometryId`：**`cq-demo-bay-v1`**

### 2.2 剖面（南北向）

```
        脊 H_r=3.8
           /\
          /  \      ← 外遮阳网层 ≈ Z=3.50（展合沿 X）
         /    \
   檐───/      \───  H_g=2.8
       |  灯   |     ← 吊灯安装面 Z=2.30
       |·······|     ← 冠层测光面 Z≈0.45–0.50
       | 床 床 |     ← 床面/基质面 ≈ Z=0.15–0.25
  南───┴───────┴───北   地坪 Z=0
     Y=0            Y=7
```

### 2.3 透光与遮阳层

| 层 | 位置 | 参数 |
|----|------|------|
| 覆盖膜 | 拱面 | `coverTransmittance = 0.65` |
| 外遮阳 | 脊下 ≈ Z=3.50 | `maxBlockFraction = 0.85`；按区电机半跨控制 |
| 内遮阳 | MVP **不做** | 记入 Won't，避免双层语义混淆 |

## 3. 功能分区与栽培床

### 3.1 区划

| zoneId | 作物 | X 范围 (m) | Y 范围 (m) | 光策略要点 |
|--------|------|------------|------------|------------|
| **ZONE-A** | 铁皮石斛（组培→栽培配方可切换） | **0.5 – 7.5** | 0.8 – 6.2 | 硬限窄；欠补过遮 |
| **ZONE-B** | 金线莲 / 设施草莓（切换演示） | **8.5 – 15.5** | 0.8 – 6.2 | 金线莲耐阴；草莓讲 DLI |
| 中央横通道 | 人行 / 管线 | **7.5 – 8.5** | 0 – 7 | 无栽培、无灯正下方优先 |

西门：西山墙中部；东门：东山墙中部。主作业口朝南外走道。

### 3.2 栽培床排布（两区对称）

每区 **3 条东西向床**（床长轴平行于 +X，利于统一吊灯间距）：

| 床位 ID | Y 起–止 (m) | 名义宽 | 角色 |
|---------|-------------|--------|------|
| BED-*-S | 1.00 – 1.80 | 0.80 | **南床**（自然光最强） |
| BED-*-M | 3.10 – 3.90 | 0.80 | 中床 |
| BED-*-N | 5.20 – 6.00 | 0.80 | **北床**（自然光偏弱） |

走道：南沿 0–1.0；床间约 1.3 m；北沿 6.0–7.0。

**基质/床面高度：** 抬高床 `Z_bed = 0.20 m`。  
**冠层名义高度：**

| 区 | 冠层顶 Z_canopy | 测光平面 Z_measure |
|----|-----------------|-------------------|
| ZONE-A 石斛 | 0.50 | **0.50** |
| ZONE-B 金线莲/草莓 | 0.40 | **0.45** |

种植密度（演示叙述，不进控制回路）：石斛丛植沿床；金线莲密植耐阴；草莓冬茬稀植强调 DLI。

    │                    │                        │

## 6. 光场计算约定（服务软件，不改物理）

| 项 | 值 |
|----|-----|
| 冠层网格 | 覆盖全棚可用床区；建议 **nx=32, ny=14**（Δx≈0.5 m，Δy≈0.5 m），`marginM=0.25` |
| 区有效 PPFD | 该区床面网格 **AVG**；告警可看 **MIN** |
| 南北自然光梯度（直射日） | 南床相对中床 **×1.06**，北床 **×0.94**（漫射日梯度缩小至 ±2%） |
| 灯贡献 | 既有余弦/半角衰减；仅对 `measurePlaneZ` 平面求值 |
| 日型 | `cq-winter-fog` / `cq-winter-clear` / `cq-summer-noon` / `cq-overcast` |

完整公式：[contracts/light-field-model.md](./contracts/light-field-model.md)（须引用本 geometry/layout ID）。
