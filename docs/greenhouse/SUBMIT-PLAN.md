## 3. 每人详细职责

### 角色 1 · 后端·控光与仿真（A 轨）
**代码域**：`com.cqu.greenhouse.*`、规则引擎、仿真 tick、工单状态机、MQTT 订阅/下发。
**关键任务**：
- [x] 光场规则：欠光补光、过光先降灯、硬限遮阳、cooldown（维护）
- [x] **M5 冻结口径**：AUTO **先执行**，超阈值建「已执行…待复核」审计 WO（非「阈值前不直发」）
- [x] **P0.3** `approve` 仅审批；`claim` 接单叙事（执行已由 AUTO 完成）
- [x] 布局 v1.5 双层补光 + 响应矩阵规划器
- [ ] MQTT 上下行契约维护（`smart-greenhouse/{sn}/…`）
**验收**：两区有效；大开度有审计工单；approve≠claim 可演示。
**口径真源**：[HANDOFF.md](../../HANDOFF.md) §4 · [CONFORMANCE.md](./CONFORMANCE.md) C1/C2 · [GAP-ASSESSMENT.md](./GAP-ASSESSMENT.md) §0。
**接口**：改字段时在 `contracts/` 补一行，通知角色 2/4。

### 角色 2 · 前端·冠层与总览（A 轨前端）
**代码域**：`web/src/views/GreenhouseView.vue`、`DashboardView.vue`、Three.js 光场、`AgriAgent.vue` 农艺助手。
**关键任务**：
- [x] 冠层 3D 棚体 + 热力切片 + 作物/设备悬停（维护）
- [x] 分区聚焦（相机半跨 + 热力压暗）+ 点选切换设备详情 + 性能（就地改色）
- [x] 工单光晕挂 `targetDeviceSn`（避免整区遮阳误亮）
- [ ] 远距密度聚合 / 状态过滤（GAP P1.2）
- [x] 全日曲线、配方切换、农艺助手知识库
**验收**：拖拽跟手；切分区有反馈；点设备可切换侧栏；助手可答核心作物问题。

### 角色 3 · 数据库与数据
**代码域**：`sql/`（schema.sql、test-data.sql、migrations/*.sql）。
**关键任务**：
- [ ] 维护 `gh_recipes / gh_zones / gh_devices / gh_work_orders` 结构与种子
- [ ] 配方/设备坐标与 `docs/greenhouse/layouts/cq-demo-bay-v1.json` 保持一致

**验收**：全新库 `init-db.ps1` 一次成功；`gh_*` 表数据与文档一致。

### 角色 4 · 角色权限与协同页（B 轨）
**代码域**：JWT 角色、`web/src/auth/rbac.ts`、设备/日志页、申请/联系/报告页。
**关键任务**：
- [ ] **R1** 六角色码种子 + 服务端守卫 + 前端 `can()` 显隐
- [ ] 设备页对接 `/greenhouse/devices`、日志页对接 `/greenhouse/control-logs`
- [ ] 工单分角色按钮：农艺“批准/驳回”、种植员“接单/完成”

**验收**：不同角色登录看到不同导航与按钮；越权调用 403。

### 角色 5 · 需求·原型·架构图（对应清单 1、2）

## 6. 答辩要点（给全体）

- **叙事主线**：重庆寡照 → 测光 → 光配方比对 → 补光/遮阳双向闭环 → 农艺工单可审计。
- **差异化亮点**：空间光场 3D + 重庆日型仿真（一天压缩 2 分钟）+ 角色分权（approve≠execute）+ 分床控光。
- **诚实边界**：光学为解析/衰减模型非实时光追；多传感门控（VPD/EC）文档有、代码未全开。
